# Site Premium para Corretor de Imóveis

Projeto estático compatível com GitHub + Netlify.

## Como publicar

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para o repositório.
3. No Netlify, clique em **Add new site > Import an existing project**.
4. Conecte o GitHub e selecione o repositório.
5. Build command: deixe vazio.
6. Publish directory: `.`
7. Clique em **Deploy site**.

## Onde editar

- Texto principal: `index.html`
- Cores e visual: `assets/css/style.css`
- Animações simples: `assets/js/main.js`
